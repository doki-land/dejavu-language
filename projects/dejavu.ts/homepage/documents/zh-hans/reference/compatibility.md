# 实现兼容性

本页把可移植的 Dejavu 规范与各宿主实现的验证证据分开。

## 状态含义

- **已验证**：指定套件完整执行并核对了预期输出。
- **部分验证**：部分用例完成，但完整声明的能力面没有完成。
- **未验证**：仓库目前没有为该能力提供可靠证据。

## 当前证据

以下状态于 2026-08-11 在仓库根目录执行 `pnpm conformance` 后记录：

| 宿主       | T1 IR 渲染 | 继承 / loader                   | 说明                                                         |
|------------|------------|---------------------------------|--------------------------------------------------------------|
| TypeScript | 部分验证   | 已由 TypeScript engine 测试验证 | 核心 T1 用例通过，但跨宿主 runner 中的 `safe_raw` 没有完成。 |

当前 conformance 命令在某个用例被所有宿主跳过时仍可能成功退出。在 runner 行为修正前，不能把最后的成功提示当成完整跨宿主
conformance 证据。

## 可移植语言表面

规范契约目前覆盖插值、注释、`if`、`loop`、表达式、`|>` 过滤器、默认 HTML 转义、`safe` / `raw`、继承、include 和 loader
解析。推迟能力只记录在 Template Contract 中，不作为宿主能力宣传。

跨多个运行时发布模板前，应固定宿主包版本并阅读其发行说明。
