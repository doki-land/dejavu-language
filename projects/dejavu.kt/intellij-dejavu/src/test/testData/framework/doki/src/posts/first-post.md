Welcome to my blog! This is my first post using the Doki template engine.

## What is Doki?

Doki is a powerful template engine that allows you to create dynamic web pages with ease.

## Features

- Simple and intuitive syntax
- Support for blocks and inheritance
- Powerful looping and conditionals
- Easy integration with other systems
